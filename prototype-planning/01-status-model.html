Problem

The calendar closes findings, not a decisionConfirmed change

Today a finding that isn't sent by its deadline becomes Expired: no checkbox, its money moves to Not disputed, and the memo can read Done. Product notes n342/n349 forbid any workaround. The client now says customers may still choose to pursue older findings — closure should come from a business outcome.

Nothing closes a dispute the Biller ignoresPotential conflict

A sent dispute waits forever, or the customer records a false Denied. "No reply yet" was removed on 2026-09-25 (a nudge); a closing result is a different thing, but it is new (C9).

Small inconsistencies that growNeeds verification

Won't pursue can be undone only before the deadline (n360) — with no calendar closure, why? A memo whose open findings are all Won't pursue shows Done while Undo is possible (L13). Answers say collected, money says recovered (L6).

Out of scope here: Implentio-managed disputesWho handles a dispute (you or Implentio) is discussed on its own in 03 · Dispute ownership. This file models only the customer's own path. The working idea for 03: "Handled by" is a layer on top of these statuses, not an extra stage — so nothing below should need to change when it lands.
What is not a problemThe meeting's example labels ("Available to dispute", "Dispute in progress", "Recovered", "Dismissed") already exist under decided names. This file keeps the existing names Existing and maps the meeting's words onto them (section 2).

Proposed model: three separate things

The meeting's list mixes where a finding is, how it ended, and facts about it. Keeping them apart (as product note n341 already demands for the data) makes every rule one line. The UI still shows one label per finding.

1 · Stage

mostly existing

Where it is. Exactly one at a time.

Ready to dispute→ In a prepared email→ Waiting on Biller→ Closed

2 · Result

+1 new

How it closed. Only when the stage is Closed.

Fully collectedPartly collectedDeniedWon't pursueClosed, no answer

Biller answers are final but editable with history (n345). Won't pursue is reversible (Undo).

The one rule that changes

Before: deadline passed && not pursued ⇒ Expired (closed). After: deadline passed ⇒ add flag. Nothing closes a finding except a customer decision (Won't pursue) or a result (answer / Closed, no answer). Newly confirmed direction; the consequences below are Unresolved.

Memo status keeps its rule Existing: any open → Ready to dispute; else any waiting → Waiting on Biller; else Done. The recovery rate is recovered ÷ (recovered + not recovered), as the tracker shows today.
